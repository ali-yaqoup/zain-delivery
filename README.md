# زين دليفري — Zain Delivery

موقع توصيل محلي لكفل حارس والقرى المجاورة.

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## الميزات

- بدون تسجيل دخول للزبائن
- محلين: **كينج بيتزا** و **ميني ماركت مطاوع**
- دفع عند الاستلام
- تتبع الطلب برقم الطلب
- لوحة تحكم لزين على `/admin`

## لوحة التحكم

- الرابط: `/admin`
- الدخول بـ **إيميل + كلمة سر** من متغيرات البيئة:
  - `ADMIN_EMAIL`
  - `ADMIN_PASSWORD`
- محليًا راجع `.env.local` / `.env.example`

## ملاحظات

أسعار وقوائم المنتجات مؤقتة ويمكن تعديلها من `src/lib/stores.ts`.
