# زين دليفري — Zain Delivery

خدمة توصيل محلية لكفل حارس والقرى المجاورة (قيرة، ديراستيا، حارس).

**الموقع:** [https://zaindelivery.shop](https://zaindelivery.shop)

## ماذا يقدّم الموقع؟

- طلب بدون تسجيل حساب
- مطاعم، ميني ماركت، وخضراوات وفواكه
- الدفع عند الاستلام
- تتبع حالة الطلب
- واجهة عربية، ودعم التثبيت كتطبيق (PWA)

## للمطوّرين

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

للإنتاج:

```bash
npm run build
npm start
```

### الإعداد

انسخ `.env.example` إلى `.env.local` وعبّئ القيم المطلوبة هناك (أو في متغيرات بيئة الاستضافة).  
لا ترفع ملفات `.env` أو أسرار حقيقية إلى Git.

### التقنيات

- Next.js (App Router)
- TypeScript + Tailwind CSS
- تخزين طلبات عبر Postgres عند التوفر
